# MiniClube

## Download

[**Baixar MiniClube para Windows**](https://github.com/mathpferreira/miniclube/releases/latest/download/MiniClube-Setup.exe)

## O Windows mostrou "O Windows protegeu o computador"?

É normal: o Windows avisa sobre qualquer programa novo que ainda não tem assinatura digital. Para instalar:

1. Clique em **Mais informações**.
2. Clique em **Executar assim mesmo**.

A instalação é automática e cria o atalho **MiniClube** na área de trabalho.
